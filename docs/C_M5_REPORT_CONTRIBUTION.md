# C 的数据复现章节与 RISE 答辩要点

供 A 汇总最终报告、E 整合展示，日期 2026-10-26。正式数值使用 [DCU 统计报告](DCU_STATISTICAL_ANALYSIS_20261015.md)，不混用历史 RTX 4060 RISE 时间。

## 数据与实验输入

主体矩阵为六方法 × 三模型 × 两数据集，共 36 单元。ImageNet 与 VOC 各冻结 460 张 eval，每单元保存四类逐图指标；轻量包共有 66,240 行指标、144 行汇总与 82,800 条稳定性 trace。每张原图五次 RGB 高斯扰动先汇总为一个稳定性观测，统计单位仍为原图。运行预算和模型输出语义由交接包的 90 份实际配置绑定，不由历史默认值推定。

ImageNet / VOC 分别采用 softmax / sigmoid。单模型忠实性主分析使用冻结目标命中组：ResNet50 / DenseNet121 / VGG16 在 ImageNet 为 408 / 371 / 363 张，在 VOC 为 387 / 388 / 400 张。跨模型配对仅使用共同命中组 332 / 353 张；全样本保留作敏感性分析。VOC 命中是冻结单目标类别为 sigmoid argmax，不是多标签 exact-match accuracy 或 mAP。

## 可复现链路

以固定 SHA-256 的 `dcu_team_handoff_20261014.zip` 为输入，在独立 Python 3.12 CPU 环境运行仓库的校验、统计、绘图和报告模块。先核对 CRC、逐文件 hash、metadata、ID、target、预测/权重身份、配置、配对 seed、五次 trace 聚合和正确组筛选，再以原图配对进行分析。代码版本、环境、命令和结果见 [C 复现记录](C_M5_REPRODUCTION.md)。

此链路独立重建统计表、图和报告；没有执行交接包内源码，也没有重新执行 GPU 归因。五次噪声归因图未归档，因此可从 trace 重算指标汇总，但不能独立从噪声图重算全部相关系数。已存基础 NPY 的展示验收与重新归因另行记录。

## RISE 结果解释

正式 RISE 预算为 4000 masks、7×7 网格、保留概率 0.5、batch32；完整配置以交接包快照为准。RISE 不需模型梯度，比较遮罩采样后的目标分数来估计归因。固定方法 seed 下，它在六个模型/数据集组合的模型命中组中平均 RGB 噪声稳定性均最高，范围为 0.99568–0.99949，见 [D 报告](DCU_STATISTICAL_ANALYSIS_20261015.md)。该结果限定于 sigma=0.005 和每图五次扰动；不是对任意扰动、预算或随机采样波动的结论。

高稳定性并不自动保证低删除 AUC。RISE 与其他方法的忠实性和耗时取舍应按单元的配对表和前沿解释，不能把均值名次直接说成显著性或通用最优。前五方法与 LIME 是两轮共享 DCU 运行，耗时只描述本批次，不可解释为独立受控速度比较。方法内相关图对应 RQ3 的指标关系，不能据此推导因果。

预算门禁用嵌套采样预算和同图参考检查近似变化，为正式预算提供工程依据；4000-mask 高预算相关不等于数学收敛证明。固定随机 seed 的输入噪声稳定性也不同于跨方法 seed 的采样稳定性。

## 答辩问答

| 问题 | 回答要点 |
| --- | --- |
| 460 张是否全都用于主排名？ | 单模型用命中组，跨模型用共同命中组，全 460 为敏感性口径；筛选不依赖归因分数 |
| 为什么稳定性不按 2300 个样本检验？ | 同图五次重复先聚合，原图是独立推断单位，避免伪重复 |
| RISE 稳定性最高为何不能说最好？ | 忠实性、稳定性和效率有取舍；结论按模型/数据集与固定预算限定 |
| 这次 C 复现了什么？ | 接收表格验收、七张派生表、四图和报告；不包括 GPU 重新归因及未保存的噪声图 |
| 为什么保留三个旧 PR 的材料？ | 保留实现贡献、脚本与原运行证据，合并历史可追溯；当前统计仍只用统一 DCU 包 |
