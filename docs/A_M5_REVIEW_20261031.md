## 报告中的解释边界

- 混合设计 AUC 七项效应显著；稳定性数据集主效应未显著，其余六项显著；不能把未显著写成等效。
- 跨数据集 raw AUC 同时变化评分激活、类别、图片总体等，只描述冻结任务评分；方法选择仍查同任务证据。
- 两类检验各有 Holm 族；WTS 的 9,999 次 bootstrap 使原始 p 分辨率为 0.0001，多数质量校正 p 为 0.0014，不能当精确极小 p 或 p=0。
- 保留 ImageNet/DenseNet121 IG/KS 均值区间跨零、秩偏 IG 的例外；保留 VOC/AUC 直接 DID 分层区间不跨零但 IID 区间跨零、秩 p=.8374。
- 方法选择六条规则与新结果相容；交互不能自动给每个方法对加显著性，也不能改变共享负载时间的解释边界。
