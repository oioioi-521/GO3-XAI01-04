## 215：名次画像居中，不代表所有方法质量都好

**观察事实。** 原图为木地板上的猫。IG 预览呈细碎纹理，Grad-CAM 显示较粗集中区域，Occlusion 是重叠窗口形成的块状分布，KernelSHAP 显示网格块，LIME 呈超像素分块。IG 的 raw AUC .45038 低于 Grad-CAM .61039，而稳定性 .60048 低于 .99793；Occlusion AUC .86079，是本图六方法中最高，尽管稳定性 .84553。这张图的六方法名次画像与候选池的中位画像 L1 距离为0，不等于每项数值接近总体均值，也不等于统计抽样代表性。

**机制假设。** 不同特征粒度、logit/概率响应和排序归一化可能共同影响这种取舍；窗口遮挡与删除评价的像素尺度不同，也可能相关。本轮没有控制变量实验，不能断言“块状解释导致高 AUC”或“粗图必然更稳”。不把灰度最亮处的视觉重合当语义定位真值。

## 3803：忠实性与输入噪声稳定性名次冲突

**观察事实。** 原图为植被背景中的鸟。按本规则，AUC/稳定性的方法名次平方差和=70，与4675并列，按较小 ID 取本例。IG AUC .61097 为六方法最低，稳定性 .72360 为六方法最低；RISE 稳定性 .99962 最高，但 AUC .81341 最高。LIME AUC .76855、稳定性 .76248；它比 RISE 的 AUC 低，但稳定性低。预览中 Grad-CAM 为鸟附近粗区域，RISE 更平滑，LIME 呈分块，不能用外观宣布哪种方法总体最优。

**机制假设。** 粗粒度聚合、扰动平滑及超像素分割可能影响噪声响应，但这里比较的是既定实现的联合差异。原图背景复杂只是一项观察，不足以证明模型依赖背景或 LIME 局部拟合失败。

## 7612：低置信命中，个体排序可与总体不同

**观察事实。** 原图为车内的狗；模型 sigmoid argmax 命中 dog，置信度 .539305，是387张命中组最低。LIME AUC .20177 为本图最低，低于 IG .36502；但 LIME 稳定性 .82359，低于 RISE .99884。IG 稳定性 .47697 为本图最低。这说明总体均值排序不要求每个个体同序；本例本身不是“LIME 失败”或预测错误。

**机制假设。** 目标分数及遮挡后的分布变化可能影响 raw AUC，但不能仅凭本图低置信证明任何机制；更不能把各类别 sigmoid 当作总和为1的 softmax 概率。raw AUC 不除原分数，故跨不同图片的绝对 AUC 比较尤其需要保留初始响应量。

## 298：预测命中与解释退化可以同时出现

**观察事实。** VOC/VGG16 命中 person，置信度 .989805。Grad-CAM 五条 trace 为3次 `both_constant`、2次 `reference_constant`，spearman 均为空、score=0、valid_rate=0；AUC .67589。本轮只从正式 trace 确认参考 map 常量及计分，未取得该 map 本体，不描述其实际像素外观。其他五方法 valid_rate=1；Occlusion AUC .13020、稳定性 .99732。常量 Grad-CAM 的像素排序缺乏解释意义，其 AUC 不能作为语义定位证据。

**机制假设。** 选定层、梯度、ReLU 和目标响应可能造成退化，但尚未逐层或逐算子检查，不宣称已定位原因。高分类置信度不能保证任一解释方法产生非退化图；本例用于解释质量控制，不代表 Grad-CAM 总体失效。

## LIME 的采样与局部拟合：有证据到哪里写到哪里

前三个正式例没有保存逐图 weighted R²，也没有本轮跨方法采样 seed 的重算。不能给215/3803/7612贴“局部拟合失败”标签。正式五次噪声测试固定方法 seed，不能作为采样方差测量。已有 LIME debug 预算审阅/8000 优化等价记录支持“部分 debug 样本仍有采样敏感性和较弱局部线性拟合”，范围仅限该记录中的 debug 总体，见 [预算审阅](LIME_DCU_BUDGET_REVIEW_20261013.md)及 [正式运行局限](LIME_DCU_RESULTS_20261013.md)。8000 是冻结预算，不是逐图收敛证明。当前以常量 Grad-CAM 作有证据的异常例，不为凑齐现象虚构正式 LIME R²。
