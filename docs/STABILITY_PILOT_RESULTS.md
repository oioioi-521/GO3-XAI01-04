# 稳定性协议候选试跑

更新时间：2026-09-22。

本试跑用于 Issue #8 的协议选择，不是正式稳定性结果，也不进入当前 Pareto/ANOVA。
环境为 Python 3.13.9、PyTorch 2.8.0、torchvision 0.23.0、Captum 0.9.0、
SciPy 1.17.1、CUDA 12.8、RTX 2080 Ti。

## 候选协议

- 在反归一化 RGB `[0,1]` 像素域加入零均值高斯噪声，裁剪到 `[0,1]` 后重新归一化；
- target 始终使用冻结 metadata 真值类别；
- 每图 5 次重复；seed 由 `SHA256(dataset, image_id, repeat_idx)` 派生，与执行顺序无关；
- 同一图片/重复的噪声在方法和模型间复用，使方法比较保持配对；
- 比较原图与扰动图 float32 attribution 的全像素 Spearman，越高越稳定；
- top-10% Jaccard 仅作为诊断，不作为主稳定性指标；
- 原图或扰动归因是常量图时不伪造为 1 分，记录明确状态和 `valid_repeats`。

复现脚本为 `analysis/pilot_stability.py`。它独立写入 pilot CSV，不污染正式
`results/per_image.csv` / `results/units.csv`。

## 40 张门禁：sigma=0.005

共 2,400 条方法级重复记录和 1,200 条去重输入扰动。整体预测保持率为 **98.17%**，
目标类别分数绝对变化均值为 0.010409；所有归因均为有限值。

## 建议冻结项

建议 Issue #8 以本候选为基础冻结：

1. `sigma=0.005`、5 repeats、真值 target、RGB 域噪声、固定 seed 派生；
2. 主指标名 `stability_spearman`，方向 `max`；
3. 每个退化重复在 trace 中记为 `degenerate`，主分数按 0 计入，避免常量解释因“完全不变”获得 1 分；
4. 同时输出 `stability_valid_rate` 作为诊断，正式报告披露退化数量；
5. 不保存全部扰动归因图；保存原图 float32 NPY、每次 seed/score/status trace 即可复现；
6. 稳定性重复不重复计算 MoRF，也不混入 `efficiency_time_ms`；
7. 使用 SciPy Spearman 的原生实现并锁版本，不再额外引入未锁定的 Quantus API。

A 的现有 float32 原图可复用。按本次实测估算，A 的 12 个单元执行 5 次扰动重归因约增加
53 分钟纯归因时间，计入模型加载、相似度和落盘后可按约 1 小时预算。

上述条目只有在 #8 经 C/D/B 复核后才成为正式协议；确认前不启动 460 张跑批。
