## 讲述稿（时间仅为预算）

### 0:00–0:35：我负责什么，实验比较什么

我负责 KernelSHAP 和六方法统计分析。KernelSHAP 使用7乘7网格的49个特征组，
以2048个联盟采样估计相对黑基线的贡献。这是固定预算近似，没有证明采样已经收敛。
统一DCU批次的执行、我负责的方法与统计，以及后续独立验收分别记录，不把共享执行全部算作个人计算。

### 0:35–1:15：RQ1与不能省略的例外

单模型比较只在该模型命中的同一批图片内配对。六组里，IG有五组平均删除AUC最低，
RISE六组平均输入噪声稳定性最高。这里没有全指标冠军。
ImageNet的DenseNet121是重要例外：KernelSHAP的平均AUC略低，但与IG的均值差区间跨零；
配对秩方向反而偏IG。因此均值点估计、均值区间和秩检验要分别讲，不能宣布某一方法显著最优。

### 1:15–2:10：交互与三因素为什么这样算

跨模型比较改用共同命中组：ImageNet332张、VOC353张。方法和模型在同一张图上重复测量，
数据集是图像间因子，原图嵌套在数据集里；五次噪声不算五倍独立样本。
AUC七项主效应和交互都显著，稳定性的数据集主效应未显著，其余六项显著。
这说明对比结构随模型和任务变化，但不代表每一个局部方法对都显著。
例如VOC的一个IG与KernelSHAP差中差，类分层区间不跨零，普通原图区间跨零，秩校正p约0.84，
所以我们保留敏感性，不用全局显著性替它下结论。

### 2:10–2:45：RQ2/RQ3与如何选方法

质量前沿每组有两到四种方法。三轴图再加入本批次记录时间，展示固定条件下的取舍，
不是普适速度排名，也不是显著性曲面。时间轴是平均毫秒的对数，跟因子分析的逐图对数变换不同。
方法内部的忠实性与稳定性相关方向也不一致，不能说两者必然冲突，更不能据相关讲因果。

### 2:45–3:00：限制与交接

所有结论都限于固定样本、权重、预算和评价协议。两个数据集的评分激活和类别不同，
不能按原始AUC跨数据集评质量冠军。下面由E展示有正式来源绑定的同图六方法案例。

## 追问速答

| 问题 | 回答要点 | 查证入口 |
|---|---|---|
| 460、371、332分别是什么？ | 每单元460张eval；371是ImageNet/DenseNet121命中组；332是三模型共同命中组。单模型和跨模型/因子分析分开取样。 | A v3 §2.1；D10/29 cohort记录 |
| 为什么不是把36个均值直接做普通ANOVA？ | 同图方法/模型观测相关；混合设计以原图为独立单位，给效应对应误差层，数据集间原图不配对。 | D10/29方法段与代码 |
| 稳定性数据集主效应不显著是什么意思？ | 在该边际对比和检验下证据不足，不是证明两任务等效；局部单元差或交互仍可存在。 | 名义p=.121215、WTS p=.1148 |
| WTS p=.0014为什么重复出现？ | 9999次bootstrap加一校正，原始p网格下界.0001；本研究14项质量族Holm后的下界.0014，不是p=0或极小p的精确值。 | D10/29 JSON超越数/族定义 |
| 为什么两种CI会给出不同直觉？ | 类分层CI条件于固定类别数；IID原图抽样让类别构成变化。ImageNet很多类别只有一张图；两者都披露，且均值CI和秩检验目标不同。 | 10/28 DID和10/29分层/IID结果 |
| 数据集×方法×模型显著能说明什么？ | 冻结任务评分下对比结构有差异；softmax/sigmoid、类别、图片总体同时变化，不能单独归因于数据集或普遍解释质量。 | A v3 §3.3 |
| 前沿是不是显著更好？ | 只是均值非支配集合；不代表前沿每一对都显著，也不保证预算/硬件变化后仍在前沿。 | 原Pareto JSON；A v3 §4 |
| 归因稳定就是对了吗？ | 输入噪声稳定不等于忠实、定位或因果正确；固定方法seed也没有测联盟/掩码重新采样的随机性。 | D方法说明；固定稳定性协议 |
| NPY是不是原始Shapley值？ | 保存的是float32归一化图；符号贡献经投影/min-max后，不能再用最终图检验原贡献可加和。 | KernelSHAP适配器和D方法段 |
| 全部工作都验收了吗？ | D计算及A接收已交；C新增统计独立复现、E展示同步/异机Demo和全组实际演练仍分别待完成。 | 本轮D复核与Issue #21 |
